# კურიერის ჯიბე

დამხმარე აპი კურიერებისთვის.

- **მთავარი** — საათის ფასი, ცვლის წამზომი, დღის მიზანი, საწვავი, ხარჯები და ვალები (რამდენი საათი უნდა იმუშაო), სწრაფი გამოთვლა, ბოლო 7 დღე
- **ფასდაკლება** — სად აქვთ კურიერებს ფასდაკლება
- **SOS** — SMS ლოკაციით შენს კურიერებს, დარეკვა, 112
- **წიგნები** — დღის ფრაზა და ქართული ლიტერატურა (ტექსტები: ვიკიწყარო)
- **სამუშაო** — ვაკანსიები და ერთჯერადი საქმეები

პირველი ეტაპი: ყველა მონაცემი ინახება ტელეფონში, რეგისტრაციის გარეშე.

ფაილები: `index.html` (აპი), `books.json` (ტექსტები), `icon.svg`, `manifest.webmanifest`.
